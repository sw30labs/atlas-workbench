# Synthetic demonstration fixtures

Every JSON file listed in `fixture_manifest.json` is human-authored,
conspicuously fictional demonstration data. No record describes a real
organization, event, loss, source, or prediction.

The emerging-risk and scenario fixtures include fictional radar classifications,
transmission paths, signposts, response options, and discussion prompts so the
dashboard can demonstrate the complete workflow without real-world claims.

The manifest applies `CC0-1.0` to these fixtures. The complete legal text is
available at [`../LICENSES/CC0-1.0.txt`](../LICENSES/CC0-1.0.txt). The
dedication covers only material the contributors have the right to dedicate;
it does not cover third-party names, marks, publications, or other excluded
material.
